## 1. Critical Issues Resolved in the Final v3.0 Audit (`Issues 2A` through `2G`)

| Audit Area | Flaw Discovered in v2.0 (`CDR-015`..`CDR-023`) | Severity | Exact v3.0 Resolution & Enforcing Boundary |
| :--- | :--- | :---: | :--- |
| **2A. Service Auth, Capability Minting & Replay Protection** | 1. **Shared Secret Forgery (`CDR-015`):** Using a single `INTERNAL_SERVICE_TOKEN` for both directions allowed a compromised planner to mint its own `X-Turn-Capability-Token` for any `userId`.<br>2. **Capability Expiry (`CDR-016`):** `15s` token TTL expired before `20s` multimodal turns completed.<br>3. **Replay Cache Eviction & Multi-Replica Claim (`CDR-017`):** LRU eviction at `10,000` entries allowed replay via cache flooding, and in-memory cache did not cover multi-replica deployments. | **`P0 Critical`** & **`P1 High`** | 1. **Split Keys (`ADR-AI-002 v3.0`):** `BFF_TO_PLANNER_HMAC_SECRET` is shared for `/internal/v1/plan`; **`BFF_CAPABILITY_SECRET` is held exclusively by `transitos_bff_gateway`** (`0` planner access).<br>2. **Turn-Aligned Deadline:** Capability token `deadlineMs = now + 18,000 ms` (`25,000 ms` multimodal) + active `inFlightTurns.get(reqId)` check on BFF.<br>3. **Fail-Closed Replay Cache:** Rejects with `503` if `10,000` unexpired entries are reached; Phase 1 is explicitly scoped as single-instance, and Phase 2 adds PostgreSQL `UNLOGGED TABLE internal_request_nonces`. |
| **2B. Quotas, Idempotency, Midnight Drift & Phase 1 Backend** | **Phase 1 SQL Mismatch & Midnight UTC Drift (`CDR-018`):** v2.0 wrote Phase 1 quota reservation in PostgreSQL SQL even though Phase 1 runs on `BffStorageEngine` (in-memory/file), and settling across `00:00:00 UTC` with `CURRENT_DATE` corrupted `reserved_tokens`. | **`P0 Critical`** | **Request-Bound `QuotaLedger` (`ADR-AI-009 v3.0`):** Defined `InMemoryJournaledQuotaLedger` (Phase 1 single-instance) and `PostgresQuotaLedger` (`ai_quota_ledger` + `ai_quota_reservations` in Phase 2). Every reservation binds `(requestId, userId, quotaDateUtc)` at reservation time and transitions `RESERVED -> SETTLED` idempotently on that exact `quotaDateUtc`. |
| **2C. Canonical Action Policy, Memory/Place Proposals & Native `0x01` Parity** | **Confirmation Contract Split & Dropped `0x01` Params (`CDR-019`):** v2.0 disagreed on header vs. JSON body for `confirmationToken`, lacked confirmation types for memory/place writes outside the 26 UI `ActionCode`s, and dropped `parameters` in Native `0x01` frames. | **`P0 Critical`** | **Unified `POST /api/v1/actions/confirm` (`ADR-AI-003 v3.0` & `ADR-AI-010 v3.0`):** Accepts JSON body `{ confirmationToken, proposalType: 'UI_ACTION' \| 'MEMORY_WRITE' \| 'SAVED_PLACE_UPSERT', actionCode, parameters, stepUpVerified }` bound to RFC 8785 JCS `params_sha256`; appends `canonicalParamsUtf8` (`u16 LE` length + bytes) to Native `0x01` frames. |
| **2D. Complete 12-Table RLS Matrix & Legacy `ai_memory` Consent Migration** | **Missing RLS on Migration `001` Tables & Silent Legacy Opt-In (`CDR-020`):** v2.0 `002_agentic_memory.up.sql` enabled RLS on new tables but left `user_profiles`, `user_settings`, `saved_places`, `attachments`, and `chat_messages` without RLS, and left existing `001` users at `ai_memory = 1`. | **`P0 Critical`** | **12-Table RLS & Consent Timestamp (`ADR-AI-004 v3.0` & `ADR-AI-008 v3.0`):** `002_agentic_memory.up.sql` enables `ENABLE` + `FORCE ROW LEVEL SECURITY` across all 10 tenant tables (`001` + `002`), adds `ai_memory_consented_at TIMESTAMPTZ DEFAULT NULL`, and resets `UPDATE user_settings SET ai_memory = 0 WHERE ai_memory_consented_at IS NULL`. |
| **2E. BFF-Authoritative Taint Latch, Decompression Bombs & Kernel Egress** | **Planner-Reported Taint Trust & Gzip Bomb Risk (`CDR-021`):** BFF trusted the planner's `taintedByExternalContent` boolean, and `SafeWebFetcher` only capped compressed socket bytes (`2 MiB`). | **`P0 Critical`** | **BFF Research Lease & Dual Caps (`ADR-AI-011 v3.0`):** Planner must call `/internal/v1/tools/acquire_research_lease` before search/fetch, which permanently latches `inFlightTurns[reqId].tainted = true` in BFF memory. `SafeWebFetcher` caps both compressed (`<= 2 MiB`) and decompressed (`<= 5 MiB`) bytes and pairs with Linux `nftables` egress rules. |
| **2F. Pinned Vercel AI SDK v6 & `zod` Compatibility** | **SDK Version & `zod@4.0.0` Build Bug (`CDR-023`):** Unpinned `ai` version and `zod@4.0.0–4.0.3` `zod-to-json-schema` crash ([`vercel/ai` Issue #7189](https://github.com/vercel/ai/issues/7189)). | **`P1 High`** | **Pinned Versions (`ADR-AI-005 v3.0`):** Pinned `ai@^6.0.306` (`stopWhen: stepCountIs(3)`) and `zod@^3.25.76` (or `>=4.0.4`). |
| **2G. `worker_threads` Parser Isolation & Provider Privacy Attestation** | **Main-Thread Event-Loop Stall & Oct 2026 Provider Logging Defaults (`CDR-022`):** [`unpdf`](https://github.com/unjs/unpdf) and `@mozilla/readability` run synchronously on the JS thread, and Oct 26, 2026 Gemini API defaults store `generateContent` for 55 days unless disabled ([Google AI Studio Docs](https://aistudio.google.com/docs/logs-datasets)). | **`P1 High`** | **Preemptible `worker_threads` & Privacy Gate (`ADR-AI-007 v3.0` & `ADR-AI-008 v3.0`):** Runs `unpdf` and `Readability` in a `128 MiB` `worker_threads` pool (`worker.terminate()` at `3,000 ms`); forces `store: false` on OpenAI and requires `*_PRIVACY_ATTESTATION` at startup in `production`. |

## 2. Final Implementation Sequence & Release Gates (`Phase 1` -> `Phase 5`)

1. **Phase 1 — Safe End-to-End Core (Single-Instance BFF + Stateless Planner):**
   - Build split-key auth (`BFF_TO_PLANNER_HMAC_SECRET` + BFF-only `BFF_CAPABILITY_SECRET`), `InMemoryJournaledQuotaLedger`, `CANONICAL_ACTION_POLICY_TABLE`, pre-hydrated turn context, `transitos_agentic_ai` (`ai@^6.0.306`), and incremental SSE / `0x00`/`0x01` streaming with `get_route_eta`, `get_weather_forecast`, and `list_user_saved_places`.
   - **Blocking Gates:** `REQ-01`..`REQ-04`, `REQ-14`..`REQ-16`, `REQ-18`, `REQ-19`, `REQ-20` (provider attestation).
2. **Phase 2 — Multi-Replica PostgreSQL 16 + `pgvector` (`FORCE RLS`), Opt-In Memory & `ConfirmationVault`:**
   - Apply `002_agentic_memory.up.sql` (10 tenant tables with `FORCE RLS` under `transitos_app_runtime` `NOBYPASSRLS`), `PostgresQuotaLedger` (`ai_quota_reservations`), `internal_request_nonces`, `ConfirmationVault` (`POST /api/v1/actions/confirm`), and `PgMemoryStore`.
   - **Blocking Gates:** `REQ-05`..`REQ-09`, `REQ-20` (10-table cascade + tombstone).
3. **Phase 3 — Safe Web Research, BFF Research Lease Taint Latch & `worker_threads` Extraction:**
   - Add `acquire_research_lease`, `SafeWebFetcher` (connect-time DNS IP pinning + `2 MiB` raw / `5 MiB` decompressed caps + `nftables`), `worker_threads` extractor (`@mozilla/readability` + `unpdf`), and `CitationValidator`.
   - **Blocking Gates:** `REQ-10`..`REQ-13`.
4. **Phase 4 — Multimodal Image Sanitization (`Sharp` `16 MP`), Attachment Excerpts & Pre-Token Provider Failover:**
   - Add `ImageSanitizer` ([Sharp](https://github.com/lovell/sharp)), `read_verified_attachment_excerpt` (`unpdf` worker), and `ModelRouter` pre-token fallback.
   - **Blocking Gates:** `REQ-14`, `REQ-17`.
5. **Phase 5 — Durable Workflows (`DBOS` in BFF), Promptfoo Red-Team CI Gates & Optional Transit Crawler:**
   - Add [DBOS Transact TS](https://github.com/dbos-inc/dbos-transact-ts) inside `transitos_bff_gateway` / `transitos_core_workers`, [Promptfoo](https://github.com/promptfoo/promptfoo) CI gates (`EVAL-06`, `EVAL-07`), and optional isolated [Crawlee](https://github.com/apify/crawlee) + [Playwright](https://github.com/microsoft/playwright-mcp) worker.
